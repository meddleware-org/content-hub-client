# Changelog

## 0.0.1 — 2026-10-30

- The package's runtime entry is the compiled `dist/index.js` (built by `prepublishOnly`), so Node-side consumers (the console's
  browser tests, the service's contract job) need no TypeScript transform; `src` is still shipped for source maps.
- `limitsFromDefinition`, `limitsForTarget` and `check` (port of the service's per-target limits and post check; Discord embed
  mode and a Mastodon instance's cached limits), with a `limits` section in `vectors.json`.
- Route table: `GET`/`PUT /api/v1/publishing` (the publishing stop switch), `GET /api/v1/preview/roadmap`, and the public `GET /public/v1/snapshot` (the signed roadmap snapshot).

- Text engine (port of the service's Rust core): parser for the canonical format, renderers, counters, segmentation,
  intent links; `vectors.json` gains counting, rendering and segmentation vectors generated by the Rust implementation.

- Route tables of the admin and public surfaces, prefixes, the CSRF header.
- Enumerations of the data model; task and platform-instance state machines (previews).
- `vectors.json` version 1: enumerations and both state machines (counting, rendering and segmentation sections
  present and empty).
