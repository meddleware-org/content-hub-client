# @meddleware/content-hub-client

The client-side contract of the content hub ([content-hub-service](https://github.com/meddleware-org/content-hub-service)):

- **routes** — every route of the admin (`/api/v1`) and public (`/public/v1`) surfaces, the prefixes and the CSRF
  header state-changing admin requests carry;
- **model** — the data model's enumerations as the API sends them;
- **state** — the server's task and platform-instance state machines, for UI previews (the server decides);
- **vectors** — `@meddleware/content-hub-client/vectors.json`, the golden vectors the Rust service and this package
  must both reproduce. This package is their home; the service keeps a copy and checks it byte for byte against the
  published file.

- **text** — the canonical post format (a small CommonMark subset), renderers per markup (plain, Markdown, Discord,
  Telegram HTML, BBCode), counters per platform method (bytes, code points, UTF-16, graphemes, X's weighted count,
  URL weights, Mastodon remote mentions), the composer's segmentation and manual-assist intent links. These are
  previews: the service's Rust implementation decides, and both reproduce `vectors.json` exactly.

**Vectors are generated by the Rust implementation** (`cargo run -p content-hub-core --example gen-vectors` in
content-hub-service), copied here, and published from this package first.

No runtime dependencies. ESM, ships TypeScript source with declarations; Node ≥ 24 or any modern bundler.

```ts
import { ADMIN_ROUTES, CSRF_HEADER, operatorMoves } from '@meddleware/content-hub-client'

operatorMoves('unknown') // ['posted', 'failed']: an uncertain send is resolved by a person, never retried
```

## Development

```bash
npm ci
npm run type-check && npm run lint && npm test && npm run check:vectors && npm run build
```

Changing an enumeration, a state machine or a route is a coordinated change: this package (published first), then
the service (its copy of `vectors.json`, its CHECK lists, its route tables).
